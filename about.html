About This Project

Built by a fan, for fans.

AnimeHub is a small internship practice project that brings together a top 10 anime list, a wallpaper download gallery, upcoming releases, and a few favorite games — built with plain HTML and CSS, plus one small bit of JavaScript for the search box on the home page.

What's under the hood

Plain HTML and CSS — every page and card is written out directly, nothing generated dynamically.

One small JavaScript file (search.js) powers just the search box on the home page.

Wallpaper downloads use a plain HTML download attribute — no script required.

All posters/wallpapers are original placeholder art — swap in your own images anytime.
